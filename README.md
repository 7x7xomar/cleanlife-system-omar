# موقع شركة CleanLife

موقع تفاعلي متكامل لشركة كلين لايف لخدمات التنظيف، مصمم بالكامل باللغة العربية وباستخدام HTML وCSS وJavaScript فقط.

## الصفحات الرئيسية

- الصفحة الرئيسية
- خدماتنا
- احجز خدمة
- الأسعار/حاسبة تكلفة
- تتبع طلب
- من نحن
- تواصل معنا
- لوحة إدارة (محلية)

## الميزات

- تصميم عصري متجاوب RTL
- حاسبة تكلفة تفاعلية
- نظام حجز متعدد الخطوات
- لوحة إدارة محلية
- نظام تقييمات وتعليقات
- دعم الوضع الليلي
- حفظ بيانات المستخدم محلياً

## طريقة التشغيل

1. افتح `index.html` في المتصفح.
2. جميع البيانات تحفظ محلياً (لا حاجة لخادم).

## رفع المشروع إلى GitHub

```powershell
cd d:\javascript_programs\cleanlife-system-omar
git init
git add .
git commit -m "إصدار أولي لموقع CleanLife"
git remote add origin https://github.com/YOUR_USERNAME/cleanlife-system-omar.git
git push -u origin master
```

استبدل `YOUR_USERNAME` باسم مستخدم GitHub الخاص بك.
